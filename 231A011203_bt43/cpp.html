CHƯƠNG 01

Làm quen với C++

C++ là ngôn ngữ lập trình đa mục đích, thường dùng để học thuật toán, phát triển phần mềm và các ứng dụng hiệu năng cao.

1. Cấu trúc chương trình

#include <iostream>
using namespace std;
int main() {
    cout << "Xin chao C++";
    return 0;
}
  • #include <iostream>: sử dụng nhập/xuất.
  • main(): hàm chính, chương trình bắt đầu chạy tại đây.
  • cout: in dữ liệu ra màn hình.
  • return 0: kết thúc chương trình thành công.

CHƯƠNG 02

Biến, kiểu dữ liệu và phép toán

Biến là vùng nhớ được đặt tên để lưu trữ dữ liệu. Một số kiểu thường gặp: int (số nguyên), double (số thực), char (ký tự), string (chuỗi) và bool (đúng/sai).

Ví dụ: tính tổng hai số

int a = 5, b = 7;
int tong = a + b;
cout << tong; // Kết quả: 12

Các toán tử cơ bản: + - * / %. Với hai số nguyên, % trả về phần dư của phép chia.

CHƯƠNG 03

Câu lệnh điều kiện

Dùng if, else if, else để lựa chọn nhánh lệnh tùy theo điều kiện.

if (n % 2 == 0) {
    cout << "So chan";
} else {
    cout << "So le";
}

Biểu thức điều kiện thường dùng: ==, !=, >, <, >=, <=, kết hợp bằng && (và), || (hoặc).

CHƯƠNG 04

Vòng lặp

Vòng lặp giúp thực hiện lặp lại một nhóm lệnh. for phù hợp khi biết số lần lặp; while kiểm tra điều kiện trước mỗi lần lặp; do...while luôn chạy ít nhất một lần.

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// In: 1 2 3 4 5
